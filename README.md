# Rocket Service Web

Sistema de gestión de órdenes de servicio técnico para motocicletas.

## Stack
- Frontend: React
- Backend: Node.js + Express
- Base de datos: MySQL (XAMPP)
- Almacenamiento imágenes: Cloudinary

## Versiones
- `v1.0` - Flujo base técnico implementado
- `v1.1` - Correcciones BD y validaciones (en curso)

## Ramas
- `main` — versión estable
- `develop` — integración
- `feature/kevin-v1.0-flujo-tecnico` — flujo técnico completo
- `feature/kevin-v1.1-correcciones` — correcciones BD y validaciones
